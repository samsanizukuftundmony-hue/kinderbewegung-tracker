# Ideen für später

- Bewegung nach Uhrzeit anzeigen.
- Tagesziel für Bewegung festlegen.
- Fortschritt grafisch anzeigen.
- Daten für mehrere Tage speichern.
- Später eventuell Bewegung automatisch erfassen.
- Später soll ein Bewegungssensor oder eine Smartwatch die Daten automatisch erfassen.
- Die Daten sollen automatisch an die Webseite/App übertragen werden.
- Die Bewegung soll nur während der Schulzeit ausgewertet werden.
