# Regeln für ChatGPT

- Die Webseite soll auf Deutsch sein.
- Die Webseite besteht aus einer einzigen HTML-Datei.
- Keine externen Bibliotheken verwenden.
- Die Webseite soll auf dem Handy gut funktionieren.
- Der Code soll einfach und verständlich sein.
- Kurze Kommentare im Code verwenden.
- Bei Änderungen immer die vollständige Datei zurückgeben.
